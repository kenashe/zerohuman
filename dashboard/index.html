Verify a decision proof (independently, from public RPC)

This check does not trust ZeroHuman's API. It reads the order transaction and the target block directly from the RPC below, recomputes keccak256(blockhash(orderBlock+5) ‖ orderTxHash) mod n, and compares it with the on-chain delivery.
